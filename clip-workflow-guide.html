Clip automation guide

CarryMinati, IShowSpeed aur Mythpat ke 5-minute source cuts se daily YouTube Shorts aur Instagram Reels tak.

Mac Terminal mein pehle repo folder kholo aur apna VPS set karo. Purane local records bhi check karne ke liye CLIPS_HISTORY_DIR ko us root folder par set karo jisme outputs/ aur work/ hain.

Mac Terminal · apna VPS address lagao
export CLIPS_SSH_HOST="root@YOUR_VPS"

1. Teeno creators ke 5-minute cuts Desktop par banao

Mac Terminal kholo. Copy button se command copy karo, paste karo aur Enter dabao. VPS password maange toh Terminal mein enter karo. Password type karte waqt screen blank reh sakti hai.

Mac Terminal
bash "tools/cut-three-to-desktop.sh"
  1. Process finish hone tak Terminal khuli rakho. Ye command koi post publish nahi karti.
  2. Files saved in ... ke baad Finder → Desktop mein Three-creator-cuts.… folder kholo.
  3. CarryMinati (CarryisLive), IShowSpeed aur Mythpat ki teen MP4 files dekho. Terminal mein har cut ka source link aur timestamp milega.

Script VPS queue aur local timestamp records mein pehle use hui source video skip karti hai. In records ke bahar ki manual posts verify nahi hoti. Missing: aaye toh us creator ki file nahi bani.

2. Scheduled Drive update ek baar VPS par install karo

Agar latest update ke liye Scheduled Drive queue enabled already mila hai, step 3 par jao. Warna Mac Terminal mein installer chalao. Ye active clip run ka wait karega. Installer khud koi post trigger nahi karta.

Mac Terminal
bash "tools/install-scheduled-drive.sh"

active aur Scheduled Drive queue enabled aaye toh bot ki private chat mein /status bhejo. Reply milne par aage badho.

Purana bot version: Usmein /clip turant job start kar sakta hai. Scheduled confirmation milne ke baad hi teen links bhejo.

3. Drive par upload karo aur Telegram se queue karo

  1. Teeno MP4 files Google Drive par upload karo. Footage wahi use karo jise clip aur repost karne ki tumhare paas permission ho.
  2. Har file par Share → General access → Anyone with the link → Viewer select karo. Download allowed rakho aur Copy link dabao. File ka link copy karo.
  3. Telegram bot ki private chat mein teen alag messages bhejo. Har message mein neeche ke example URL ki jagah us creator ka actual Drive link paste karo.
Telegram · sample message
/clip https://drive.google.com/file/d/YOUR_FILE_ID/view

Har link par bot ko 8:45 AM and 4:45 PM IST slots wala queued reply dena chahiye. Phir status check karo:

Telegram
/status

Teen jobs scheduled dikhni chahiye. Bot link aur next timestamp save karta hai. Har slot mein teen alag sources se ek-ek 45-second clip ka target hai. Usable segment na mile toh kuch clips skip ho sakti hain. Run slot ke time start hota hai. Render aur uploads uske baad complete hote hain.

Mac band ho sakta hai jab files Drive par upload ho chuki hon aur bot ne unhe scheduled queue mein confirm kar diya ho. Drive route ko YouTube source cookies ki zaroorat nahi hoti.

4. Upload aur poori video khatam hone tak verify karo

  1. Pehla scheduled slot: Bot ke messages mein teen jobs dekho. Har successful job ke output mein source time range aur YouTube aur Instagram ka result hoga.
  2. Links check karo: YouTube Short aur Instagram Reel dono ke links open karo. Kisi ek ke liye not verified aaye toh us platform ka upload confirm nahi hai.
  3. Agla slot: Wahi Drive link apni saved position se resume karega. /status mein Progress: … of … dekho. scheduled ka matlab source ke aur segments baaki hain.
  4. Video ka end: Jab bot Send a new /clip link kahe, us creator ka replacement link bhejo. Baaki creators ki links dobara bhejne ki zaroorat nahi.

5-minute source mein maximum 6 poori 45-second windows hain. Har slot mein ek eligible window publish ho toh us source ko lagbhag 3 din lag sakte hain. Quality check segments skip kar sakta hai. End mein 45 seconds se chhota hissa bach sakta hai.

Immediate upload: /now <Drive link> worker free hote hi ek actual upload job banata hai. Daily scheduling ke liye /clip use karo.

Telegram service ka read-only check

Mac Terminal
ssh "$CLIPS_SSH_HOST" 'systemctl is-active clip-telegram-drive.service; journalctl -u clip-telegram-drive.service -n 20 --no-pager'

Telegram–Drive service pehle se install nahi ho toh

Google Cloud mein Drivepool → Google Drive API → Credentials par Drive API-restricted key ready rakho. Installer hidden prompt mein key lega. Pehle bot mein /status reply verify karo, phir step 2 ka scheduled update install karo.

Mac Terminal · initial install only
bash "tools/install-telegram-drive.sh"

YouTube cookies reject ho jaayein toh

Ye recovery YouTube-source downloads aur Desktop cuts ke liye hai. Drive link route independently chal sakta hai.

  1. Chrome Incognito mein YouTube sign in karo. Usi tab mein https://www.youtube.com/robots.txt kholo.
  2. Cookie extension se current site ka Netscape export lo. Nayi file Downloads/youtube-cookies.txt naam se save karo, phir Incognito close karo. Cookie file secret rakho.
  3. Sirf source access refresh karna ho toh ye command chalao:
Mac Terminal · refresh only
bash "tools/clip-cookie-refresh.sh" refresh

Cookies refreshed. No clip run started. aaye toh Desktop cuts command phir chala sakte ho. Aaj ka missed slot bhi publish karna ho toh sirf ek retry command use karo:

Mac Terminal · morning retry
bash "tools/clip-cookie-refresh.sh" morning
Mac Terminal · evening retry
bash "tools/clip-cookie-refresh.sh" evening

No test passed aaye toh existing cookies replace nahi hui aur retry start nahi hui. addOnDisposeCallback ya No video formats found ke saath solver warnings aayein toh downloader version bhi check karo. Us situation mein cookie export akela fix confirm nahi karta.

Offline guide. Commands cloned repo ke root se chalao. CLIPS_SSH_HOST ko apne VPS par set karo. Telegram status aur platform links se live result confirm karo.
